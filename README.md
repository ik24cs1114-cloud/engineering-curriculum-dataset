# Engineering Curriculum Dataset (ECD)

## Overview

This dataset contains **20,000 topic-document pairs** from **100 engineering subjects**. Each document is a descriptive sentence about a specific engineering topic, designed for topic modeling, text classification, and educational NLP research.

## Quick Facts

| Property | Value |
|----------|-------|
| Total Documents | 20,000 |
| Unique Subjects | 100 |
| Unique Topics | 900 |
| Avg Document Length | 11.9 words |
| File Format | CSV |
| File Size | 2.95 MB |
| License | MIT |
